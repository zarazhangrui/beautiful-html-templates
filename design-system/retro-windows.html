01 — Overview

The Conceit Is Total

Retro Windows is a Windows 95 / 98 desktop-OS aesthetic rendered as a slide template. Every slide is a window — beveled chrome, a navy-gradient title bar, three system buttons, and a body of application-style content. There are no slide titles in the modern sense, only window titles styled as filenames (README.DOC, METRICS.LOG). Half playful nostalgia, half functional dashboard — a deck that reads as software running on a CRT monitor.

03 — Typography

One System Face, Two Accents

The workhorse is the OS system stack (MS Sans Serif → Segoe UI → Tahoma) — never a custom display sans. Press Start 2P and VT323 are nostalgic accents only: one or two moments per deck. Sizes are fixed integer pixels (12, 13, 14, 16, 18, 22, 30, 32) — the OS-UI illusion breaks at fluid type.

06 — Depth & Shape

Depth By Bevel, Never Shadow

All depth comes from two-tone asymmetric borders plus inset shadows — no blurred box-shadow, no drop-shadow. Two states only, and corners are square everywhere.

RAISED
white top/left + black right/bottom
+ inset 1px white / -1px #404040
SUNKEN
#404040 top/left + white right/bottom
the inverse — a recessed well
Border Vocabulary
  • 2px two-tone bevel — windows, panels, buttons, dots
  • 1px solid — table cells, win-icon outline
  • 1px stacked pair — the engraved hr-retro rule
The Rules
  • Border-radius is 0 system-wide
  • Borders are never coloured — two-tone only
  • Active press inverts the bevel
  • The CRT overlay is the one atmospheric layer

07 — Do & Don't

Hold The Era

DO
  • Wrap every slide in a window with a navy title bar, a filename title, and the three-button cluster.
  • Use the bevel technique on every panel, button, and window — it is the system's identity.
  • Set primary headlines in navy weight 700 — the application-title voice.
  • Pack each slide densely with stacked panels, group-boxes, and a status footer.
  • Use the status colours semantically: green OK, red error, yellow moderate, cyan tertiary.
  • Apply integer pixel font sizes and keep the CRT overlay on every slide.
DON'T
  • Round any corner — every shape is a strict rectangle.
  • Use blurred box-shadow or drop-shadow; all depth is bevel-based.
  • Introduce modern saturated brand colours outside the Win9x set.
  • Colour the borders — two-tone white+black / gray+white only.
  • Use Press Start 2P or VT323 for body text, or rem/em/clamp for body sizes.
  • Compose a sparse slide with one headline and empty space — it reads as broken.

08 — 中文 / CJK

A System-Font Localization

Retro Windows is a system-font deck, so it collapses to one CJK family for every Latin-system role: 思源黑体 Noto Sans SC. That preserves the “software UI” register — a Win9x app rendered its Simplified-Chinese build in a single system CJK face, not a display + body pairing. The pixel and terminal accents stay Latin-only by design.

复古视窗系统
每一张幻灯片都是一个窗口：斜角边框、海军蓝标题栏、系统字体正文。标题栏文件名可保留 Latin（如 METRICS.LOG）以维持系统怀旧感，也可用「中文描述符 + 扩展名」如 季度指标.LOG。状态徽章干净利落：就绪、在线、通过、警告 — 语义色彩照常贯穿。盘古之白：在中文与 Latin 之间插入空格。
