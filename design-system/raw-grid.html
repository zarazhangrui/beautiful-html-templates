01 — Overview

Borders Are The Grid

Raw Grid is built on a single premise: 3px solid black borders are the layout. No margins, no gaps, no rounded corners, no gradients. When two regions meet, a 3px black line separates them — that line is the entire grid system. The type is deliberately non-decorative: the native system sans, weight 900 uppercase, no web fonts.

02 — Colours

Black Structure, Two Pastels

Six tokens, four roles: white canvas, black structure (borders, text, shadows, label fills), and two muted pastels — blush pink and sage green — as region fills only, never on text. The pastels are pale enough that black text stays fully legible; the system never inverts text over an accent.

03 — Typography

System Sans, No Web Fonts

The entire system runs on the native stack — Segoe UI / system-ui / Helvetica. Loading zero web fonts is the aesthetic statement: this is software, not a print artifact. The weight axis is the only expressive tool — 900 uppercase display against 500 sentence-case body.

05 — Layout

Borders, Not Gaps

When a slide divides into columns, the cells share a single 3px black border and meet it directly — no gap, no margin. Internal padding gives breathing room inside cells; gaps between cells do not exist. That edge-to-edge meeting is the system's most distinctive structural choice.

06 — Depth & Shape

Two Shadows, Zero Blur

Exactly two shadow values — 6px and 4px hard offsets in solid black, always bottom-right, never blurred, never colored. Most apparent depth actually comes from the 3px borders; shadow is reserved for elements that float above their surface.

07 — Do & Don't

Hold The Borders

Do
  • Use 3px solid black borders on every division — let them touch edge-to-edge.
  • Set display in weight 900 uppercase with negative tracking; body in 500 sentence case.
  • Use the black label pill as the universal section tag.
  • Pair pink with green — warm with cool — never two of one.
  • Add the arrow-prefix to every CTA and place wallpaper numerals behind content.
Don't
  • Load any web font — the native system stack is the identity.
  • Round a corner, blur a shadow, or colour a border.
  • Put display-weight text in sentence case, or use weights 400 / 600.
  • Invert text over pink, green, or gray — pastels carry black text.
  • Put gaps between regions — borders are the separators.
08 — 中文 / CJK

One Family, Black Pills

Strategy A: a single CJK family — 思源黑体 Noto Sans SC — preserves the system's typographic monoculture. It's the one concession to web fonts (no system CJK renders weight 900 consistently). Brutalist density comes from the weight ladder, not from the uppercase that Chinese lacks.
